================================================================================
DATASET: MS MARCO (Raw TSV Files)
LOCATION: data/ directory
PURPOSE: The raw source data for collections, queries, and relevance labels.
FORMAT:  Tab-Separated Values (.tsv)
SOURCE:  Microsoft MS MARCO Passage Ranking Dataset
================================================================================

This file describes the schema and representation for the primary data files
used in the SBERT and LexBERT pipelines.

================================================================================

2. QUERIES (data/queries.train.tsv, data/queries.dev.tsv)
================================================================================
Schema: [query_id]  [query_text]

Examples:
121352	define extreme
634306	what does chattel mean on credit history
920825	what was the great leap forward brainly
510633	tattoo fixers how much does it cost
737889	what is decentralization process.

================================================================================
3. RELEVANCE LABELS / QRELS (data/qrels.train.tsv, data/qrels.dev.tsv)
================================================================================
Schema: [query_id]  [unused_zero]  [passage_id]  [relevance_score]
Note: In MS MARCO, relevance_score is always 1 for positive pairs.

Examples:
1185869	0	0	1
1185868	0	16	1
597651	0	49	1
403613	0	60	1
1183785	0	389	1

================================================================================
SUMMARY
================================================================================
These raw files are processed by the scripts in /preprocessing/ to create 
the JSON training pairs and evaluation candidates used by the models.
